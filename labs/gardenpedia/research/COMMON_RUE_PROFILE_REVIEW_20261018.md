# Common Rue established-plant review — 2026-10-18

Identity: *Ruta graveolens* L., species-level ornamental subshrub (NC State identifies Rutaceae; the existing taxonomy record retains this accepted name and has no taxonomic conflict).

Primary source: NC State Extension Plant Toolbox, Common Rue — https://plants.ces.ncsu.edu/plants/ruta-graveolens/common-name/common-rue/

The profile now distinguishes established outdoor care (full sun to part shade; moderately fertile, moist but well-drained soil; avoid wet soil; winter mulch in northern zones) from indoor/system fit, which remains unknown. NC State describes a 2–3 ft woody subshrub, early-spring pruning, self-seeding, and yellow flower clusters whose prose timing (mid-to-late summer) differs from the structured trait table (summer/fall). The profile preserves that source-internal bloom-period discrepancy. Pollinator and swallowtail-host value is included as ornamental/wildlife use.

Safety remains explicit: NC State reports contact irritation and serious poisoning symptoms from large ingestion, recommends protective clothing/gloves when handling, and notes root rot in poorly drained soil. No culinary dose, medicinal benefit, or safe-food claim is inferred. The profile remains **partial** because the selected source disagrees internally on flowering period.
