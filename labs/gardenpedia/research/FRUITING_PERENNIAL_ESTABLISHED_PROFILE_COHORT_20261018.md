# Fruiting perennial established-plant review — 2026-10-18

Reviewed four published identities against their existing canonical records:

- Hardy Kiwi — `Actinidia arguta`
- Honeyberry / haskap — `Lonicera caerulea`
- Saskatoon serviceberry — `Amelanchier alnifolia`
- Wintergreen — `Gaultheria procumbens`

## Material improvements and scope

- Hardy Kiwi: added NC State's species-level winter pruning target (8–10 buds
  per stem) and summer control of overlong branches. Cultivar, sex, trellis
  design, and indoor-system suitability remain unspecified/unknown. The
  propagation note does not become a Seed Profile because the source gives only
  partial stratification information, not a complete seed-to-established-plant
  protocol.
- Honeyberry: added UMN's distinction that compatible pollen varieties must be
  genetically distinct, clarified the short/variety-dependent harvest window
  and hand-picking context, and added dormant-pruning guidance with the
  U-Pick-specific canopy objective kept explicitly scoped. No cultivar pair,
  harvest date, or pruning calendar is inferred. The home propagation method
  remains unresolved, so the record stays partial.
- Saskatoon: added University of Saskatchewan guidance that fruit ripens
  unevenly, requires repeated picking, and should be cooled promptly. The
  Saskatchewan harvest calendar is not generalized. Landscape-size ranges
  remain at genus/cultivar scope; home propagation remains unresolved, so the
  record stays partial.
- Wintergreen: added fall fruit timing and the source's edible-fruit statement,
  without inventing serving guidance or a safety guarantee. The existing
  warning that NC State no longer recommends leaf tea remains prominent.

All four profiles retain unknown indoor/hydroponic fields rather than treating
outdoor conditions as indoor-system evidence. EN/ES carry the same new claims
and caveats. No Seed Profiles, private records, identities, or canonical
compatibility values were added or changed.
