# Lavender and petunia profile enrichment — 2026-10-18

Scope: enrich only existing public Plant Profile records `lavender-vera` and
`petunia-dwarf-bedding-mixed`. No Seed Profile, private inventory, taxonomy,
or runtime changes were made for this cohort.

## Lavender Vera

- Added cultivation, growth-range context, and pruning guidance in English and
  Spanish using `usu-lavender`.
- Utah State Extension's guidance applies to English lavender generally. Its
  size range varies by variety; it is not asserted as a measured Vera dimension
  or indoor-clearance promise. The source's pruning recommendation is likewise
  not represented as a Vera-specific trial result.
- Existing harvest-timing source differences and saturated-root concern were
  preserved. Profile remains `partial` pending full identity-specific QA.

## Dwarf Bedding Mixed Petunia

- Added group-level cultivation and deadheading context in English and Spanish
  using `umn-petunias`.
- The catalog identity remains product-level `Petunia spp.`; the mixed label is
  not assigned a species, cultivar, or growth class. UMN distinguishes
  grandiflora, multiflora, milliflora, and spreading types, so no class-specific

- Existing product-page flowering/thinning statements were preserved. Profile
  remains `partial` pending growth-class and identity-specific QA.
