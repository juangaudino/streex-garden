# Mexican sunflower established-plant review — 2026-10-18

Identity: `mexican-sunflower-tithonia-rotundifolia` — `Tithonia rotundifolia` at species scope; no cultivar assigned.

## Evidence used

- NC State Extension supports species identity, a 3–6 ft regional height and 2–3 ft width, full sun, well-drained soil, flowering from mid-summer into fall, pollinator/cut-flower use, conditional staking and deadheading.
- Wisconsin Extension adds a 4–6+ ft regional height, branching habit, coarse/hairy leaves, brittle stems and fragile hollow flower stalks, outdoor planting distances, soil/fertilization cautions, pinching, early-summer shearing and stem-breakage observations.

## Editorial decisions

- Kept the institutional height ranges distinct rather than averaging them; compatibility height remains unknown because the reported regional ranges do not establish one reconciled value. The NC State 2–3 ft outdoor width remains available with explicit regional scope.
- Added useful established-plant facts about leaf/flower appearance, outdoor spacing, weak stems from rich soil/heavy fertilization, conditional support, pinching/shearing, deadheading and brittle flower stalks. Soil spacing is not represented as pod spacing.
- Aligned EN and ES. Removed the unsupported `bushy` compatibility value; the existing `upright` value is supported by NC State's “erect” habit. Indoor light and hydroponic fit remain unknown.
- Did not add a cultivar, edible use, cut-flower vase-life claim, or universal cut stage. The evidence supports ornamental cut-flower use but does not establish a species-specific harvest stage or conditioning technique, so the profile remains **partial**.
