# Petunia Harvest Use review — 2026-10-18

## Evidence

- University of Minnesota Extension, *Growing petunias*: when petunias are
  blooming abundantly, an occasional stem may be cut for a bouquet; leaves that
  would be submerged in vase water should be removed. The source does not state
  a product-specific cut stage, stem length, conditioning method, or vase life.
- Gardyn Help Center, *Pink Petunia*: supports the product-specific statement
  that its Pink Petunia selection is not edible. This is not generalized to
  other Petunia records.

## Editorial changes

- Added bilingual, identity-scoped ornamental bouquet use for Cascading Petunia
  (AeroGarden product), Pink Petunia (Gardyn product), and Dwarf Bedding Mixed
  Colors (unidentified product mix).
- Reused general Petunia guidance only for the limited bouquet action; no
  cultivar-level performance, cut timing, stem length, vase life, edible status,
  or species-level certainty was inferred.
- Cascading Petunia remains partial because the AeroGarden-supplied seed lot is
  not taxonomically identified. No Plant Profile status was upgraded.
- Added one public source-registry record with a distinct local ID for the
  public source so these Harvest Use claims resolve without relying on a
  private source-registry entry.

## Validation scope

The content is represented in `harvest-use-richness-additions.json`, which the
existing Gardenpedia adapter already merges. Source metadata is mirrored in
the existing public source expansion file. JSON syntax, local Petunia source
resolution, bilingual parity, and inventory alignment were checked. A broader
duplicate-key audit found four pre-existing conflicting tomato records in the
same Harvest Use overlay; they are not part of this Petunia edit and still need
reconciliation before whole-file key uniqueness can pass. Identical duplicate
source metadata entries were removed. The publisher was not run because it
loads private owned-seed data.
