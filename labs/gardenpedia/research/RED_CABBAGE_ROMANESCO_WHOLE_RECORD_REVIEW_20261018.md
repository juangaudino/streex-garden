# Red Cabbage and Romanesco whole-record review — 2026-10-18

## Red Cabbage

- Identity remains the generic red-cabbage horticultural type within
  *Brassica oleracea*, not Red Acre, Red Danish, or an identified packet line.
  UW–Madison's A3684 lists Red Acre and Red Danish as specialty cabbage
  cultivars; this supports the type context, not traits of this identity.
- Corrected an evidence mismatch: the identity section had cited a Brussels-
  sprouts guide. It now cites UW–Madison A3684. Established head growth,
  cool-season cultivation, moisture, growing-point protection, harvest and
  splitting remain supported at cabbage-crop scope by UMN Extension.
- EN/ES translation, Seed Profile, and the existing crop-level Harvest Use
  record were checked. Unknown mature dimensions and hydroponic fit remain
  explicit; neither blocks this outdoor cabbage profile.

## Romanesco Cauliflower

- Catalog identity remains Romanesco type within *Brassica oleracea*; no named
  seed selection such as Veronica or Puntoverde is assigned.
- UW–Madison supports the spiral head morphology, variable size, outdoor care,
  named caterpillar pests, dense-head harvest, lack of typical side-shoot
  regrowth, and mild raw/cooked culinary use. Crop-level UMN cauliflower
  moisture guidance remains distinct from Romanesco-specific claims.
- Added bilingual Harvest Use from the existing UW–Madison Romanesco source.
  It describes raw or cauliflower/broccoli-style use without inventing a recipe
  or cooking time. Existing Seed Profile germination gaps remain seed-stage
  information and are not copied into Plant Profile.
- Indoor/hydroponic fit, system dimensions and nutrient mapping remain unknown;
  no nutrient-engine mapping is asserted.
