# Tomato type and Harvest Use cohort — 2026-10-17

## Scope

Reviewed three existing records only: `roma-tomato`, `beefsteak-tomato`, and `yellow-pear-tomato`. This was an enrichment pass, not a full audit or completion declaration. At the time of that pass, all three were `partial` in the 501-identity inventory.

## Editorial distinctions and evidence

- **Roma** is represented as a paste/plum horticultural class, not one cultivar. Johnny's describes the class as generally meatier and less juicy and lists sauce/processing use, while offering both determinate and indeterminate varieties. The profile therefore avoids a class-wide growth-habit or cultivar-performance claim. Harvest Use adds type-scoped cooked-sauce guidance; canning remains explicitly gated to an exact current tested recipe.
- **Beefsteak** is represented as a large-fruited slicing class, not a single cultivar. Johnny's supports the meaty/juicy type description and sandwich/burger use. The profile adds this bounded fresh-slice use without claiming fixed fruit dimensions, plant habit, or yield.
- **Yellow Pear** has a named-variety source from UF/IFAS: golden pear-shaped fruit about 1–2 inches, mild flavor, vigorous vines reported above 8 feet, support, moisture management to reduce cracking, and salad use in the Florida source context. Vine length is not treated as indoor footprint, and no hydroponic suitability or universal pruning program is inferred.

## Harvest Use

Added one bilingual, source-linked use method to each existing record. Existing harvest, freezing, and safe-canning guidance remains. No new Harvest Use identity record was created; catalog coverage therefore remains unchanged.

## Disposition

These changes improve identity differentiation and practical use guidance but do not establish full completeness. Cultivar-specific performance, local outcomes, and indoor/hydroponic behavior remain unclaimed where evidence is absent. The inventory's `partial` statuses are retained pending broader editorial QA of every required section and source scope.
