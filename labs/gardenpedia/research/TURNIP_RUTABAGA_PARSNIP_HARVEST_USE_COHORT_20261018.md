# Turnip, rutabaga, and parsnip Harvest Use cohort — 2026-10-18

This bounded cohort added post-harvest guidance to four canonical profiles and
expanded the existing canonical parsnip record. It does not mark any profile
complete; each remains subject to individual Plant Profile review.

## Canonical identities

- `turnip-purple-top-white-globe` — named *Brassica rapa* variety; general turnip food-use claims remain crop-level.
- `hakurei-turnip` — named Hakurei F1 salad turnip; raw root and edible-top claims use the supplier's product scope, with general turnip guidance identified separately.
- `tokyo-cross-turnip` — named Tokyo Cross F1; Takii's fresh-market description is distinct from UMN's crop-level raw/cooked turnip guidance.
- `rutabaga-brassica-napus` — *Brassica napus* rutabaga type, kept distinct from *Brassica rapa* turnips; cooked root, edible leaves, and root-cellar storage are separately scoped.
- `parsnip-pastinaca-sativa` — existing canonical *Pastinaca sativa* record; enriched without creating a duplicate alias record.

## Evidence and editorial boundary

UMN Extension's turnip/rutabaga guidance supports crop-level edible parts,
preparation and storage distinctions. Johnny's and Takii support only the named
turnip product characteristics stated in their respective methods. Iowa State
Extension supports parsnip-like-carrot preparation, soup use and household
refrigerator handling; Illinois Extension adds roasting and mashed preparation.
No recipe temperatures, preservation process, cultivar flavor, or indoor
harvest-size threshold was invented.

The four new canonical Harvest Use identities are Purple Top White Globe,
Hakurei, Tokyo Cross, and rutabaga. The parsnip change updates the already
published `parsnip-pastinaca-sativa` record. A non-canonical raw `parsnip` ID
was not added to the public Harvest Use layer.
